# About the game
This is a sandbox game project I've created by myself, it's about playing around with objects, ragdolls, fruits! (yes you read right)
The game has 4 maps, each of them unique, and consists of 2 main gamemodes Sandbox and Survival:
  *Sandbox: The player can mess around with the entities as much as they'd want without having to worry about death.
  Survival: The objective of the player is to finish through all of the waves, which progressively get harder, whilst ridding all of the zombies in ways they please.*
The game consists around a toolbar that can be used to access 6 tools:
 *1. Hand tool, used to thrust items away from the player.
  2.Magnet ray, it takes posession of the item you right click on, and the scrollwheel can be used to pull it closer, or to repel it from the player.
  3. Item spawnner, pretty self-explanatory.
  4. Helium Balloons, you can now attach balloons to any object or ragdoll to make it fly.
  5. Rocket Launcher, used to shoot missiles at objects... and Zombies.
  6. Trasher, used to get rid of redundant objects you don’t want lying around.*
One of the main takeaways from the game is the Physics, I've spent a lot of time trying to refine them to make it highly realistic.
